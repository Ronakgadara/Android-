# 💬 ChatApp

A modern Android Chat Application built using **Java**, **Firebase Authentication**, and **Firebase Realtime Database**. The app provides secure one-to-one messaging with user authentication, profile management, dark/light theme support, and various account settings.

## ✨ Features

- 🔐 User Registration & Login
- 🔑 Forgot Password
- 👤 User Profile Management
- 💬 One-to-One Real-Time Chat
- 📱 User List
- 🌙 Dark & ☀️ Light Theme Support
- ⚙️ Settings Screen
- 🔒 Change Password
- 🚫 Disable Account
- 🔥 Firebase Authentication
- ☁️ Firebase Realtime Database
- 🚀 Splash Screen
- 🎨 Clean and User-Friendly UI

## 🛠️ Technologies Used

- Java
- Android Studio
- Firebase Authentication
- Firebase Realtime Database
- Material Design Components
- XML Layouts
- Gradle (Kotlin DSL)

## 🚀 Getting Started

### Prerequisites

- Android Studio
- JDK 17 or above
- Firebase Project

### Installation

1. Clone the repository

```bash
git clone https://github.com/Ronakgadara/ChatApp.git
```

2. Open the project in Android Studio.

3. Connect your Firebase project.

4. Download the `google-services.json` file from Firebase Console.

5. Place it inside the `app/` directory.

6. Sync Gradle and run the application.
